# Harr's Recreation Center

Business ID: `BUS-014`. Address: 505 Main Street (`B-002`). Operator/license applicant: Carl R. Harr (`P-094`).

The City historic-resource **directory synthesis** reports **Harr's Recreation Center at 505 Main in 1945** (`E-032` / `S-033`), but the exact underlying directory title/effective year/page is still unresolved. Visual review of the City's 2000 Downtown Historic Re-Survey selected bibliography found Pacific Directory Service volumes for **1941 Oregon City** and **1948 Clackamas County**, but no listed 1945 directory. Therefore retain the City 1945 chronology, but do not imply that the project has already inspected a specifically identified 1945 directory page. See `../evidence/source-captures/2000-downtown-survey-1945-harr-source-provenance-gap-2026-09-04.md`.

Commission text of 11 February 1948 names Harr as a pool-hall operator without first name/business/address; a later-1948 liquor-license list directly identifies **Carl R. Harr — Harr's Recreation Center — 505 Main Street** (`E-127` / `S-142`). The retrieved municipal text was not page-image certified, and the later excerpt lacks its opening meeting page.

This proves Harr's is not a Farr transcription error. Farr's is a separate business; transition date, opening/closing, exact 1945 directory citation, and property ownership remain unresolved.

See the [505 Main unified timeline](../timelines/505-main.md).

## 1946–1948 county-directory timing caution

The target Pacific Directory Service county volume later cited as **1947–48 / 1948** is now tied to a documented county-wide data-gathering campaign underway in **August–September 1946** (`E-201` / `evidence/source-captures/1946-1948-clackamas-county-directory-production-retrieval-route-2026-09-04.md`). If Harr / Harr's Recreation Center appears at 505 in the eventual directory pages, the listing may reflect a late-1946 canvass rather than a condition first observed in 1948; the actual page and front matter remain required.

## 708 Monroe false-path closure
