# Title-Abstract Records

This folder preserves title abstracts and official title-abstract finding records used in property-chain research.

## OHS MSS 1503 index

- Repository PDF: `ohs-mss-1503-title-abstracts-index.pdf`
- Source: `S-109`
- Evidence: `E-095`
- Canonical PDF: https://www.ohs.org/research-and-library/research-help/upload/TitleAbstractsIndex_forWebsite_PDFA.pdf

The committed 24-page PDF is the **index**, not the underlying title abstract. Its target first-page row was visually inspected and contains an internal scope conflict: the title names Block 4, Lots 3 and 4, while the separate Lot field lists 3, 4, and 5. The actual MSS 1503 Box 19 abstract remains an open manual-retrieval callout.
