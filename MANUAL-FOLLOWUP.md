# Manual Follow-Up Dashboard

Last reconciled: **5 September 2026** against `main` at `a40d260c3c7b5e1d97ded41fe01e7ee4ffabc33c`.

This is the central human-action page for research that requires an email, phone call, records request, paid lookup, restricted account, library/archive visit, physical-source inspection, or other project-steward action outside the normal online research pass.

Use this page to answer three questions:

1. **What do I personally need to do next?**
2. **Who do I contact and what exactly do I ask for?**
3. **Has the request already been sent, answered, received, reviewed, and integrated?**

Detailed evidence, source provenance, uncertainty, and historical interpretation remain in `evidence/`, `registers/`, building/business/person records, and `registers/year-status.md`. This dashboard does **not** promote a retrieval lead into a historical fact.

## Status vocabulary

Use these exact workflow states on this page:

- **NOT CONTACTED** — manual route identified; no request sent.
- **DRAFT READY** — copy/paste request text is preserved below.
- **VERIFY / PURCHASE** — a physical item or paid service appears available; confirm before paying.
- **SENT** — request submitted; record date/channel.
- **WAITING** — request acknowledged or pending.
- **RESPONSE RECEIVED** — reply arrived but historical material is not yet fully reviewed.
- **MATERIAL ACQUIRED** — scans/photos/records obtained but not yet integrated.
- **INTEGRATED** — received material visually reviewed and repository records synchronized.
- **CLOSED** — completed, or explicitly closed by the project steward with reason preserved.

**Sending a request is not completion.** A manual callout closes only after the response/material is reviewed and integrated, or the project steward explicitly closes it.
