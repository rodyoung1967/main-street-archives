# Morning Enterprise image captures

This directory holds image captures from the *Morning Enterprise* as a source title distinct from the *Oregon City Courier*.

## Cataloged capture

- `IMG-0714` — `1911-01-10-george-harding-druggist-511-main-screenshot.png`
- Source/evidence: `S-143` / `E-128`
- Printed content: George A. Harding, druggist, **511 Main Street**, **Next Door to Postoffice**.
- The legacy filename incorrectly suggested a circa-1915/1916 *Courier* item. Visual inspection identifies the capture as *Morning Enterprise*, 10 January 1911, page/image 3; the original path and SHA-256 are preserved in the photo metadata register.
