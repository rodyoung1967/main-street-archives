# Historic Photo Sources

This is the canonical photo-source area for The Main Street Archive.

## Suggested Organization

```text
media/photos/
  503-main/
  505-main/
  507-main/
  main-street-block/
  intersections/
  aerials/
```

Create subfolders when actual source files are ready to be added; empty placeholder folder trees are not necessary.

## What Belongs Where

### `503-main/`

Use for photographs and scans primarily related to 503 Main Street, including building exterior/interior views, family-history images tied to 503, Kwality Cafe / New Kwality Cafe / Larry's Kwality Cafe imagery, and material useful to the 503/505 boundary question.

### `505-main/`

Use for photographs and scans primarily related to 505 Main Street, including building exterior/interior views, 505 Tavern / The 505 / Brass Rail / Dug Inn / Thirsty Duck imagery, rear-addition or footprint evidence, and material useful to the 503/505 boundary question.

Tax statements, assessor documents, and similar records do **not** belong here; store them under `records/` even when they contain useful images or sketches.

### `507-main/`

Use for photographs and scans primarily related to 507 Main / the Harding Building, including Harding Building, Harding Drug Store, Tony's Restaurant, bakery/fire-era, replacement-building, and current-site images.

### `main-street-block/` and `intersections/`

Use for wider streetscapes, storefront groupings, parade/crowd views, commercial-district context, orientation, address-boundary evidence, neighboring tenants, and building-massing comparisons.

### `aerials/`

Use for aerial/overhead source images and photocompare series.

## Metadata and Evidence

Register images in `../photo-metadata-register.md`, the canonical image/media metadata register. Link evidentiary images to `../../evidence/evidence-register.md` and `../../evidence/source-register.md` as appropriate.

Keep originals unchanged. Store cropped, enhanced, annotated, or otherwise derivative versions separately and label them as derivatives.
