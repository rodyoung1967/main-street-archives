# Main Street Archive

This repository documents the history of selected Oregon City Main Street buildings, businesses, people, maps, photographs, and family/business connections.

Use `ARCHIVE_INDEX.md` as the primary navigation page and `timeline.md` for the chronological overview. Evidence and provenance are tracked under `evidence/`, with source records in `evidence/source-register.md`, unresolved items in `evidence/open-questions.md`, and active research targets in `evidence/research-leads.md`.

## Core accuracy rules

- Keep **503 Main** and **505 Main** as separate buildings and separate business/property chains.
- **The Wheel was only at 503 Main.**
- “The Wheel Tavern” was not an official historical business name; preserve it only when quoting a source that used that wording.
- Distinguish business ownership/operation from real-estate ownership.
- Label oral history, project metadata, and family recollection separately from primary documentary evidence.
- Never infer an exact address, date, transfer, or identity from proximity or later records when direct evidence is absent.

## Evidence handling

Whenever possible, preserve the original source binary in the appropriate repository folder **and** retain the canonical/original source URL in the source register. If a source can be verified online but the current tooling cannot transfer its binary, preserve a source-capture/provenance note with the canonical URL and add the binary to the physical-mirroring backlog rather than implying that the original file is already archived.
