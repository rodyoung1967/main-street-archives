Date reviewed: **7 September 2026**

Status: **OFFICIAL NATIONAL REGISTER NOMINATION / SECONDARY DIRECTORY CITATION; NOMINATION PAGE VISUALLY VERIFIED; UNDERLYING 1953 DIRECTORY PAGE NOT RECOVERED; NO 505 OCCUPANCY CLAIM.**

Purpose: preserve an independently printed internal-page control for the unrecovered **1953 T. W. Salisbury Oregon City directory**, the source currently targeted to identify the proprietor/operator behind the Oregon SHPO survey wording **“Well's Recreation” at 505 Main**.

## Source

West Linn Historic City Hall, National Register of Historic Places Registration Form, hosted by the City of West Linn:

`https://westlinnoregon.gov/sites/default/files/fileattachments/communications/page/54306/final_nomination_application_city_hall_and_area_history.pdf`

The source is a National Park Service / National Register registration form for **Historic City Hall, West Linn, Clackamas County, Oregon**.

## Visual review

The original hosted PDF was opened and **PDF page 19 / file page index 18** was visually inspected on 7 September 2026.

Footnote 64 visibly reads:

**`Salisbury’s City Directory for Oregon City, Oregon [and surrounding communities], 1953, 192 [listing for US Government].`**

The footnote supports the nomination text identifying George W. T. Doty as West Linn postmaster through at least 1953. This project is not adopting that postmaster claim for the 505 chronology; the value here is the nomination's exact citation to the same Salisbury directory and an internal printed page number.

## Research value for 505 Main

This citation supplies a useful independent control for the target directory:

- it confirms that another official historic-research product used a **1953 Salisbury Oregon City directory**;
- it provides the exact internal citation **page 192** for a known `US Government` listing;
- page 192 can be used as an edition/pagination check when an Ancestry, MyHeritage, FamilySearch, Gale/Research Publications Reel 26, or other image copy becomes accessible; and
- it may help distinguish the correct Salisbury volume from a mislabeled or incomplete derivative.

It does **not** identify the page containing 505 Main and does not recover any `Well's Recreation`, Harr, Wells/Well variant, proprietor, telephone number, or 9179 entry.

## Evidence boundary

Classification is **OFFICIAL NATIONAL REGISTER NOMINATION / SECONDARY DIRECTORY CITATION**. The nomination page itself is visually verified, but **Salisbury directory page 192 has not been visually inspected in this research environment**. The citation therefore cannot be promoted to primary directory evidence.

Do not infer from this control:

- that the exact title wording in the footnote is the directory's title-page transcription;
- that page 192 contains any 505 Main material;
- that `Well's Recreation` used any particular spelling in the original directory;
- who owned or operated the 505 business; or
- any Harr → Well's transition date.
