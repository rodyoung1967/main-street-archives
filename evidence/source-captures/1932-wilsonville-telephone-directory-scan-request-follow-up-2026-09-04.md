# August 1932 Oregon City telephone directory — Wilsonville scan-request follow-up

Date reviewed: 4 September 2026

Status: **PHYSICAL HOLDING CONFIRMED + CURRENT REMOTE REFERENCE ROUTE + READY-TO-SEND SCAN REQUEST. DIRECTORY CONTENTS NOT YET INSPECTED; NO FARR/505 CLAIM PROMOTED.**

Purpose: convert the already confirmed August 1932 Wilsonville Public Library holding into a precise remote reference request aimed at the active Farr / 505 Main / pool-hall question.

## Exact physical source

Wilsonville Public Library's Northwest Heritage Index identifies:

> **OR CLAC D-OR.C 1932T — Telephone Directory, Oregon City, Clackamas County, Oregon, August 1932. (Pacific Telephone & Telegraph Co., 1932.)**

Official index:

`https://www.wilsonvillelibrary.org/sites/default/files/fileattachments/library/page/26561/nw_heritage_index_2023-04-25.pdf`

The index states that the directory was indexed only to identify communities covered **in addition to Oregon City**. Individual Oregon City subscribers and businesses therefore should not be expected to appear in the public Northwest Heritage Index even if they are printed in the actual directory.

The public index gives later page ranges for several communities—Beavercreek pp. 17–19, Colton p. 19, Molalla pp. 19–21, Milwaukie pp. 21–24, Oak Grove pp. 24–27 and others—which confirms an actual multi-community directory volume and suggests the Oregon City section occupies earlier pages. **Do not infer an exact Oregon City page range without opening the volume.**

## Why this request is especially important

The final 2024–2025 McLean National Register nomination contains a parenthetical note saying “no directory in 1932” in one of its office-address discussions. That cannot be interpreted literally as no 1932 Oregon City directory existing because Wilsonville independently catalogs this August 1932 PT&T volume.

## Fixed inspection request

Ask the library to inspect or copy the **complete Oregon City portion relevant to business/subscriber identification**, not only a single surname hit. At minimum preserve:

1. the directory cover/title/publication page;
2. **Farr, Edwin F. / Edwin Franklin / E. F. Farr**;
3. **Farr, Alice**;
4. **Farr's Pool Hall** or any Farr business listing;
5. **505 Main Street** and **505½ Main Street**, if street addresses are printed;
6. neighboring **501, 503, 507, 509 and 511 Main Street** entries encountered;
7. all Oregon City entries/classifications for **pool hall, pool room, billiards, recreation, cigars/tobacco, soft drinks**, or related terms;
8. all named Oregon City pool/billiard operators in the volume, so the small contemporary business universe is preserved;
9. known comparison names kept separate in the project: **Harr, Timms, Leland & Little, Ed Wheeler, McAnulty & Barry**;
10. any address/street guide that allows 505/505½ to be checked independently of the alphabetical subscriber list.

For every relevant entry preserve exact printed wording, page number, subscriber/business name, address, telephone number and classification heading.
