It also provides a plausible framework for the observed physical difference between 503 and 505 — including the possibility that 505 extends farther rearward or otherwise crosses a different lot configuration — but the current descriptions alone do **not** prove the historical building footprint or rear-wall chronology.

## Historical-record caution

Do **not** automatically use these modern Block 4 descriptions as if they were the same indexing convention used in every nineteenth- or early-twentieth-century source. Earlier project notes also contain references to a historical **Block 26** reconstruction framework. The relationship between those numbering systems/plats must be resolved before comparing them directly.

For the 1922–1925 assessment/tax-roll retrieval, search both by:
