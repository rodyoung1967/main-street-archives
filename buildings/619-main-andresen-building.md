# 619 Main Street — Andresen Building Address

## Archive ID

- Building ID: `B-014`
- Related business: `BUS-031`
- Related evidence: `E-119`, `E-120`
- Related sources: `S-133`, `S-134`

## What Is Established

A visually reviewed 6 July 1916 report says the Electric Store and power-company offices had moved one door north to the **Andresen Building, 619 Main**. Selected later advertisements repeat 619, and a 4 January 1917 advertisement directly prints the Andresen Building and 619 Main address.

## Limits

The address evidence does not establish ownership, lease terms, every Andresen Building tenant, or that the building name always mapped to 619. An earlier 1908 Andresen Building reference is not assigned this later number without an independent continuity source.
